# TextFind IP Provenance

The tag `textfind-ip-baseline-2026-08-20` establishes a
repository-level provenance baseline.

The tag does not represent the creation or first publication date
of the materials contained in this repository.

The repository contains Git history predating this baseline,
including earlier commits through which individual theses,
RFCs, research notes, specifications, and related materials
were introduced and subsequently evolved.

Where those commits were previously pushed to the public GitHub
repository, their presence on GitHub predates the creation of
the baseline tag.

The historical Git commit graph should therefore be preserved
when evaluating the provenance and evolution of individual
documents.
